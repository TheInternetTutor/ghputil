Refined layout prototype · 20 functions · 30 illustrative call events

Function track Unconditional call Conditional call Arrowhead points to callee

Reading the matrix: each horizontal track is a function; each successive vertical column is one statically inferred call event. A connector begins on the caller's track and ends on the callee's track. Separate event columns prevent connectors from crossing. Self-recursion is shown as a small loop within its event column. This is an illustrative stress-test dataset, not a trace of a real program.
